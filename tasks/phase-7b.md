# Phase 7b: polish after use

Branch `phase-7b-polish` off `main`. Blocked by: Phases 6 and 7a merged, and at least a
week of Leo using the MVP (so the list below can be re-ordered by what actually annoyed
him). About four days.

Outcome: the MVP feels finished: text streams in with a Stop button, dark theme, a few
suggestions on an empty chat, search and rename in the sidebar, Haiku-written titles, and a
browser test suite that covers the shell.

Decisions this phase builds on: ADR 0006, 0009.

## Step 0 (Leo)

A week of use and a short list of what to change first.

## Tasks

### Task 7b.1: Streaming deltas and Stop

**Description:** The prose streams token by token after the tool loop, and the runner can
stop a reply.

**Acceptance criteria:**
- [ ] The agent's final turn uses the Messages streaming API; `delta` events carry text,
      `done` ends the reply; the `chart` event keeps its place before the first delta
      (ADR 0009).
- [ ] A Stop button aborts the request; the partial text is saved as the reply with a
      "stopped" marker and shown as such; usage records the tokens actually billed.
- [ ] Mock mode streams its canned answer in word chunks so the UI path is testable.
- [ ] `AgentTurn` renders deltas without re-parsing the whole text on every chunk
      (parse once on `done`, show raw text while streaming).

**Verification:**
- [ ] Tests pass: backend scripted-model test for delta order; frontend test for Stop.
- [ ] Manual check: a live question streams and Stop works mid-sentence.

**Blocked by:** none

**Files likely touched:** `backend/internal/agent/agent.go`, `backend/internal/api/chat.go`,
`backend/internal/api/sse.go`, `backend/internal/mockchat/mockchat.go`,
`frontend/src/lib/useChat.js`, `frontend/src/components/AgentTurn.vue`,
`frontend/src/components/Composer.vue`.

**Estimated scope:** M

### Task 7b.3: Suggestions on an empty chat

**Description:** Three question chips when a chat is empty, drawn from the runner's
recent data.

**Acceptance criteria:**
- [ ] `GET /suggestions` returns three questions generated by `claude-haiku-5-5` from a
      one-call summary of the last 14 days (activities count, average sleep, latest
      training status), cached per runner for 24 h in `usage`-adjacent storage; mock mode
      returns fixed ones.
- [ ] Tapping a chip sends it as a question.

**Verification:**
- [ ] Tests pass: handler test with a scripted Haiku response.

**Blocked by:** none

**Files likely touched:** `backend/internal/api/suggestions.go` (new),
`frontend/src/components/EmptyChat.vue` (new).

**Estimated scope:** S

### Task 7b.5: Haiku 5.5 chat titles

**Description:** Titles that read like topics, not first sentences.

**Acceptance criteria:**
- [ ] After the first reply in a chat, a background call to `claude-haiku-5-5` writes a
      title of at most six words; on failure the first question stays the title.
- [ ] The sidebar updates without a reload (the stream's `done` carries the title, or
      `GET /chats` is re-fetched).

**Verification:**
